# Keeping everyone safe

A menu row that opens the safeguarding page: the scheme's promises (`rules.js`), then a line
from each feature that adds one, then placeholders for checks and the safeguarding lead.

**Slot `safety.notes`:** `{ order, text() }`, one sentence about what that feature does to keep
people safe. Items vanish with their feature, so the page never claims more than the app does.
